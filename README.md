# Deutsch mit AI 🇩🇪

A small project documenting how I use AI to support my German learning.

I currently have **A2 German** and I am actively working to improve it. I created this project to show one practical way I use AI in everyday life: I write something in German first, then use AI to help me understand my mistakes, improve the sentence, and turn those mistakes into new practice exercises.

The goal is not to have AI do the learning for me. I use it as a practice partner alongside my German classes so I can get immediate feedback and understand *why* something is wrong.

## My learning process

1. I write the German sentence or message myself.
2. I ask AI to correct it without changing the meaning.
3. I ask for a simple explanation of my mistakes.
4. I rewrite the sentence and compare the versions.
5. I ask AI to create a short exercise based on the mistake so I can practise it again.

## A prompt I use

> I am learning German at A2 level. Please correct the German text I wrote, but keep my original meaning. Explain my mistakes in simple English, tell me the grammar rule I should remember, and then give me one short exercise so I can practise the same point myself. Do not make the German unnecessarily advanced.

## What I am learning about AI

This project has also helped me learn how to give AI clearer instructions. I have found that asking for a correction alone is less useful than asking it to explain the reason, keep the language at my level, and create a follow-up exercise. I still check the output and use my course material and classes as my main learning sources.

## Why I made this public

I wanted to document a simple, real example of how I am learning to use AI rather than create a technical project just for the sake of it. I plan to add more examples as my German improves.
